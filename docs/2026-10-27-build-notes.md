## Addresses and phone

Director, incorporator, and head-office addresses use one shared Canadian address pattern on Forms 1, 2, 3, 7, 10, and 11. Head office is the same component on every filing that asks for it. Phone numbers on the cover letter use the shared phone fields.

## Subflows

Add and edit pages for directors, incorporators, and amalgamating corporations open an error summary. Each summary link moves focus to the field that failed.

## Review

Review pages list each step as its own section, with **Edit** back to that step. Person rows (directors and incorporators) use the same labels on the card and on the review.

## Labels

Field captions across those forms use sentence case. Examples include official email, first name, and residential address.
